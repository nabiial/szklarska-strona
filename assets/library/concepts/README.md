Zdjęcia zapisuj jako WebP pod dokładnie tymi nazwami i w podanej kolejności. Karuzele mają przygotowane wszystkie slajdy; do czasu dodania plików wyświetlają pola zastępcze z nazwą brakującego pliku.

Pionowe zdjęcie w galerii pensjonatu zostanie wykryte automatycznie i wyświetlone bez przycinania. Pozostałe zdjęcia poziome wypełnią szeroki kadr karuzeli.
